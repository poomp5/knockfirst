# LukLan (ลูกหลาน)

AI call screener for elderly parents: trusted numbers ring grandma as normal, unknown callers talk to a polite Thai AI assistant first, and the family approves or blocks them from the LukLan Android app.

> 🚧 U-Hackathon 2026 (AI track), work in progress. The full README for judges lands Fri 16 Oct.
